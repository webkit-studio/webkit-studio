# Styly motion videa

Pojmenovaný styl v zadání dá výrazně jiný výsledek než „udělej to moderní“. Vyber podle toho, co má video říct, ne podle toho, co je zrovna populární.

| Styl | Jak vypadá | Kdy sedí |
| --- | --- | --- |
| Kinetická typografie | Slova jsou hlavní herec, střih na rytmus | Launch, citace, manifest |
| Švýcarský editoriál | Tvrdý grid, velká čísla, groteska, hodně prázdna | B2B, data, seriózní značka |
| Papírová koláž | Vystřižené tvary, stíny, stop motion 8–12 fps | Lidské, řemeslné, hravé |
| Editoriální explainer | Papírová textura, výstřižky, zvýraznění fixou, mapy | Příběh, historie, souvislosti |
| Matematický explainer | Tmavé pozadí, čáry se kreslí, vzorce, plynulé transformace | Vysvětlení mechanismu nebo principu |
| Izometrie | Prostorové diagramy pod úhlem 30° | Procesy, systémy, logistika |
| Šrafování a pérovka | Rytina, tenké čáry, tón šrafurou | Tradice, řemeslo, dlouhá historie firmy |
| Skicák | Ruční čára, tužka, papír | Nápad, koncept, začátek projektu |
| Risografie | 2–3 přímé barvy, zrno, posunutý soutisk | Kultura, kreativní obory |
| Blueprint | Modrý technický výkres, kóty, mřížka | Technika, výroba, stavba |
| Terminál a glitch | Neproporcionální písmo, kurzor, řádkování | Vývojáři, AI, data |
| UI demo | Skutečné obrazovky, kurzor, zoom na detail | Aplikace, SaaS, dashboard |
| Datová animace | Rostoucí grafy, počítadla, mapy | Reporty, výsledky (jen ověřená data) |
| Neobrutalismus | Tlusté obrysy, tvrdé stíny, ploché barvy | Odvážné značky, startupy |
| Morfující tvary | Organické tvary se přelévají | Abstraktní značka, přechody |
| Pixel art | Retro, nízké rozlišení | Hravé, herní |
| Měkké 3D | Zaoblené tvary jako z modelíny | Přátelské, rodinné |
| Filmová titulková sekvence | Pomalé, elegantní, hodně tmy | Prémiová značka, událost |
| Mixed media | Foto, papír a kresba dohromady | Kampaň, sociální sítě |
| 3D scéna | three.js nebo Blender přes MCP, světlo, materiály | Produkt, prostor, architektura |

## Jak styl zadat

Jméno stylu nestačí. Přidej tři věci:

1. **Paletu** z design systému (styl ji nemá přebít).
2. **Tempo** (fps, délka scén).
3. **Jednu referenci** (obrázek nebo video), pokud ji máš. Reference na kompozici a rytmus, obsah vlastní.
